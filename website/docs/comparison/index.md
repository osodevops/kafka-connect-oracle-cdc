# Comparison

**Status:** the feature comparison follows the parity matrix in the design documents and is
published with the first release. This project never publishes database benchmark figures;
instead the `bench` module ships the workload generator and correctness oracle so you can
measure throughput, latency and memory on your own database under its own licence terms, and
compare connectors side by side with the Debezium profile of the Docker Compose lab.
