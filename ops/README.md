# ops

Monitoring assets for the OSO CDC Connector for Oracle Database (ADR-0013).

| File | What it is |
|---|---|
| `jmx-exporter/oracle-cdc.yml` | JMX Prometheus exporter rules: one per numeric attribute of the task MXBean `sh.oso.cdc:type=task,server=<cdc.topic.prefix>`, named `oracle_cdc_<attribute>` (counters end in `_total`) with a `server` label. Generated by `MetricsReferenceTest`; do not edit by hand. |
| `grafana/oracle-cdc-connector.json` | Grafana dashboard: SCN lag, time behind source, throughput, open, spilled and journaled transactions, buffer and spill use, step duration, retries, reconnects, DLQ and decode failures, queue depth. |
| `alerts/prometheus-rules.yaml` | Prometheus alert rules: task not reporting, engine not advancing, behind source, DLQ records, buffer and spill near their limits, repeated reconnects. |

Attach the exporter to the Connect worker as a Java agent, for example
`KAFKA_OPTS=-javaagent:/opt/jmx_prometheus_javaagent.jar=9404:/opt/oracle-cdc.yml`, or merge the
rules into the worker's existing exporter configuration. `MetricsReferenceTest` fails the build if
the dashboard or the alert rules use a metric name that the rules do not export. The attribute
reference is website/docs/reference/metrics.md.
