# LogMiner from inside a PDB as a local user

What per-PDB mining (START_LOGMNR with an SCN range and no ADD_LOGFILE, connected to the PDB as a local user with LOGMINING) does on Oracle Database Free. It decides the range mining mode for Amazon RDS with the CDB architecture and Autonomous Database (ADR-0027).

Generated by the `pdb-local-mining` spike in `e2e-tests` against Oracle Database Free and checked on every CI run. Edit by re-running with `-Dreference.update=true`, never by hand.

## Facts

| Question | Answer |
|---|---|
| A second session's START_LOGMNR while the first is open | ok |
| ADD_LOGFILE of an archived log from the PDB | ORA-65040 |
| Column values of those rows | RS_ID set, SSN set, THREAD# 1, XIDUSN set, SRC_CON_ID the PDB's, SRC_CON_NAME FREEPDB1, CON_ID the PDB's |
| DBMS_LOGMNR_D.BUILD into the redo from the PDB | ok |
| Rows of the table after the log switch | INSERT, UPDATE |
| Rows of the table seen before a log switch | INSERT, UPDATE |
| START_LOGMNR again after the log is archived | ok |
| START_LOGMNR for a range below the oldest redo (STARTSCN 1) | ORA-01291 |
| START_LOGMNR with DICT_FROM_REDO_LOGS + DDL_DICT_TRACKING, no ADD_LOGFILE | ORA-01371 |
| START_LOGMNR with an end SCN beyond the current SCN | ok |
| START_LOGMNR, SCN range, online catalog, no ADD_LOGFILE | ok |
| SYS_CONTEXT CLOUD_SERVICE on Oracle Database Free | null |
| SYS_CONTEXT CON_NAME of the session | FREEPDB1 |
| V$ARCHIVED_LOG readable from the PDB | yes, with rows |
| V$ARCHIVE_DEST_STATUS readable from the PDB | yes, with rows |
| V$DATABASE readable from the PDB | yes, with rows |
| V$LOG readable from the PDB | yes, with rows |
| V$LOGMNR_LOGS rows after the start | populated |
| V$THREAD readable from the PDB | yes, with rows |
