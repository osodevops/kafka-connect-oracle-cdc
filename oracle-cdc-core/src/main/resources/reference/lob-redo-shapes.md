# LogMiner rows for LOB statements

The rows LogMiner emits for statements on a table with CLOB, NCLOB and BLOB columns and `ALL COLUMNS` supplemental logging, on SecureFile (`LOB_SF`) and BasicFile (`LOB_BF`) storage, mined with `DICT_FROM_ONLINE_CATALOG`, `NO_ROWID_IN_STMT` and `NO_SQL_DELIMITER`, and the undo rows of savepoint rollbacks. Fixes the LOB assembly, grouping and undo rules of PRD-00 CORE-DEC-6 and CORE-TX-2 (ADR-0015). Rows are attributed to their statement by XID; `+` marks a row that repeats, a ROWID is `placeholder` (all A) or `real`.

Generated by the `lob-redo-shapes` spike in `e2e-tests` against Oracle Database Free and checked on every CI run. Edit by re-running with `-Dreference.update=true`, never by hand.

## LOB row fields

| Fact | Observed |
|---|---|
| OPERATION_CODE of DELETE | 2 |
| OPERATION_CODE of INSERT | 1 |
| OPERATION_CODE of INTERNAL | 9 |
| OPERATION_CODE of LOB_ERASE | 29 |
| OPERATION_CODE of LOB_TRIM | 11 |
| OPERATION_CODE of LOB_WRITE | 10 |
| OPERATION_CODE of UPDATE | 3 |
| Rows with OPERATION_CODE 9 (documented as SEL_LOB_LOCATOR, labelled INTERNAL) | STATUS 0, SQL_REDO null |
| SQL_REDO of those rows | DECLARE ... BEGIN select "<column>" into <locator> from <table> where <non-LOB columns> for update; <buffer assignment>; dbms_lob.<call>; END; |
| STATUS and INFO of LOB_WRITE, LOB_TRIM and LOB_ERASE rows | STATUS 2, INFO "LOB sql_redo not re-executable" |
| Text write amounts count | characters (code points): a character outside the BMP counts once |
| Undo block address (UBABLK) of LOB rows | LOB_ERASE zero; LOB_TRIM zero; LOB_WRITE zero |

## Savepoint and statement rollbacks
